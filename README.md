# Reasoning Bench

A small, reproducible benchmark that measures **specific reasoning abilities** of LLMs under controlled conditions, and checks whether those abilities survive harmless changes to the question.

> This benchmark does not measure "general reasoning" or general intelligence. It measures the listed abilities, on the listed tasks, under the listed conditions.

## Core idea

1. Every question is generated by code, so the answer is verified by code, not opinion.
2. Every question has three versions: **original**, **surface-perturbed** (renamed, reordered), and **distractor-added** (irrelevant details).
3. Each model is run 5 times per question. We report mean and variance.
4. The headline metric is the **robustness gap**: accuracy on original minus accuracy on perturbed.
5. A private held-out set (never published) guards against contamination.

## Repo layout

```
reasoning-bench/
  README.md
  tracks/                 one folder per ability, each with a SPEC.md
  generators/             Python code that produces questions + answer keys
  data/public/            published dev set
  data/private/           held-out set (git-ignored, never uploaded)
  runner/                 one script to run all models
  results/                raw logs + summary tables
  docs/                   methodology, spec template, limitations
```

## Reproduce

```
pip install -r requirements.txt
python runner/run.py --track assumption_detection --models config/models.yaml --runs 5
python runner/report.py
```

## Limitations

- Small question counts per track; confidence intervals are reported and are wide.
- Generated questions are cleaner than real-world problems.
- Public questions can leak into future training data; the private set reduces but does not remove this.
- Scores depend on the prompt format; the exact prompts are logged.
